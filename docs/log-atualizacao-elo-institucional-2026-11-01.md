# Log editorial — 1º de novembro de 2026

## Alterações de código

- Marca editorial atualizada de **ELO.UFRB** para **ELO INSTITUCIONAL** em textos, navegação, títulos, metadados e geração estática. A vinculação à Universidade Federal do Recôncavo da Bahia foi preservada.
- Nova seção na página Idealizador com seis recortes do Portfólio Ilustrado de Antônio Mateus Soares (65 páginas, arquivo fornecido pelo responsável), incluindo reconhecimento em Cachoeira, palestras, entrevistas e publicações.
- Adequação tipográfica de logomarca e hero para o nome maior, e estilos responsivos para o novo acervo.
- Nomes de usuários, e-mails, URLs, rotas e nomes físicos de arquivos históricos permanecem inalterados para evitar links quebrados.

## Imagens do portfólio

As fotografias originais foram extraídas do PDF enviado pelo responsável e disponibilizadas em pacote separado. Esta alteração textual **não publica esses arquivos binários no repositório**, nem afirma que a integração visual dessas imagens está concluída. A página nova apresenta informações documentadas no portfólio, sem atribuir automaticamente atividades pessoais ao projeto.

## Instagram

A consulta pública não permitiu confirmar publicações novas posteriores às já registradas no acervo. Os conteúdos anteriormente verificados no Instagram foram preservados, sem duplicação.

## Pendências

- Incorporar o pacote binário de imagens do portfólio ao GitHub e associar os arquivos às seções apropriadas.
- Executar npm run build e npm run check sobre a árvore completa após a incorporação das imagens.
- Publicar o novo build na hospedagem Cloudflare Workers, caso não exista integração automática.
- Substituir eventual marca antiga embutida dentro de imagens rasterizadas, se presente.
